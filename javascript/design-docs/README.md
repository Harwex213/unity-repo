# design-docs

Просмотрщик дизайн-документов: слева список документов, справа canvas с zoom и pan.

```sh
npm install
npm run dev        # dev-сервер, порт выбирает ОС
npm run build      # сборка в dist/
npm run typecheck
```

## Управление

- Колесо мыши — зум вокруг курсора. Pinch на тачпаде — тоже зум.
- Перетаскивание мышью или одним пальцем — pan.
- Два пальца — pan и зум вокруг середины между пальцами.
- Двойной клик или кнопка «Вписать» — показать весь документ.

## Слои

| путь | роль |
| --- | --- |
| `src/core/` | типы и математика камеры: `zoomAt`, `panBy`, `fitRect` |
| `src/canvas/` | движок: pointer- и wheel-события → камера, сетка, DPR, вызов `draw` документа |
| `src/kit/` | примитивы wireframe: рамки, тексты, стрелки со скруглёнными углами, гексы, пиктограммы |
| `src/documents/` | документы. Каждый документ — папка, список — `src/documents/index.ts` |
| `src/ui/` | React: боковая панель и `CanvasView`. Выбранный документ хранится в URL hash |

Документ — это `bounds` и функция `draw(ctx)` в мировых координатах.
Движок ничего не знает о документах, документы рисуют только через `src/kit/`.

Новый документ: папка `src/documents/<id>/index.ts` с объектом `TDocument` и строка в `src/documents/index.ts`.
