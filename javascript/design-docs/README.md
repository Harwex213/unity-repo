# design-docs

Просмотрщик дизайн-документов: слева список документов, справа canvas с zoom и pan.

```sh
npm install
npm run dev        # dev-сервер, порт выбирает ОС
npm run build      # сборка в dist/
npm run check:all  # изоляция документов и типы всего проекта

npm run check -- <id>                  # изоляция и типы одного документа
npm run snapshot -- <id> [x,y,w,h …]   # PNG документа в .snapshots/<id>/
npm run new-doc -- <id> "<title>" "<description>" [order]
```

## Управление

- Колесо мыши — зум вокруг курсора. Pinch на тачпаде — тоже зум.
- Перетаскивание мышью или одним пальцем — pan.
- Два пальца — pan и зум вокруг середины между пальцами.
- Кнопка «Вписать» — показать весь документ.
- Двойной клик по тексту — выделить весь блок текста. ⌘C копирует его, строки разделены переводом строки.
- Кнопка «Notes» справа сверху — заметки документа: список свободных записей. Записи можно добавлять (⌘Enter), менять и удалять.
  Они хранятся в `src/documents/<id>/notes.json`. Правка работает только в `npm run dev`; собранная версия показывает заметки на момент сборки.
- Ссылка `#<id>@x,y,w,h` открывает документ на участке листа (мировые координаты).

## Слои

| путь | роль |
| --- | --- |
| `src/core/` | типы и математика камеры: `zoomAt`, `panBy`, `fitRect` |
| `src/canvas/` | движок: pointer- и wheel-события → камера, сетка, DPR, вызов `draw` документа |
| `src/kit/` | общие примитивы wireframe: базовая палитра, рамки, тексты, стрелки, гексы, картинки |
| `src/documents/<id>/` | один документ: код, ассеты, своя палитра. Изолирован от других документов |
| `src/documents/registry.ts` | находит все `src/documents/<id>/index.ts` при сборке |
| `src/ui/` | React: боковая панель и `CanvasView`. Документ и участок хранятся в URL hash |
| `scripts/` | проверка изоляции, проверка и снимок одного документа, шаблон нового документа |

Документ — папка `src/documents/<id>/` с `index.ts`, который экспортирует `doc: TDocument`.
Документ импортирует только из своей папки, `src/kit/` и `src/core/`. Общий код не импортирует документы.
Поэтому документы можно править параллельно: правка одного не ломает проверку и снимок другого.
Правила работы — в `CLAUDE.md`.
