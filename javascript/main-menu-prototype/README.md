# Главное меню «Острова»

Кинематографичное главное меню: экран студии Harwex World, затем планета трескается,
взрывается, и из пыли выходит уцелевший остров, над которым появляется HUD. Стек тот же,
что в `ostrov-prototype`: React, rspack, TypeScript, three.js. Музыка лежит в
`src/audio/background-music.aac`, эффекты синтезируются в браузере.

```bash
npm install
npm run dev        # сервер на свободном порту, адрес будет в консоли
npm run build      # сборка в dist/
npm run typecheck
```

## Управление

| Клавиша | Действие |
| --- | --- |
| любая клавиша, клик на чёрном экране | запустить заставку с музыкой |
| любая клавиша, клик во время заставки | пропустить заставку |
| ↑ ↓, Home, End, мышь | выбор пункта |
| Enter, клик | выбрать пункт (пока заглушка) |
| ← → | сложность |
| R | заставка заново |
| M | звук |

Браузер не даёт играть звук до первого действия пользователя. Заставка привязана к музыке,
поэтому она ждёт нажатия на экране «Нажмите любую клавишу». Если браузер уже разрешил звук,
этого экрана нет. `?t=3.4` в адресе останавливает кадр на нужной секунде.

## Раскадровка

Все моменты собраны в `TIMELINE` в `src/core/timeline.ts`:

| Секунды | Что происходит | Что в треке |
| --- | --- | --- |
| 0.5–5.6 | логотип Harwex World проявляется и гаснет на чёрном | тихий пэд |
| 2.61 | полоса света идёт по логотипу | первый чёткий акцент |
| 5.7–7.3 | чёрный экран проявляется в планету, HUD нет | на 6.3 входит бас |
| 7.45–9.95 | трещины расходятся, растёт гул | бас держится |
| 9.95–10.3 | вдох: свет и гул падают | |
| 10.3 | взрыв | подъём, низкая середина входит на 10.35–10.44 |
| 11.8 | остров выходит из пыли | |
| 13.5+ | HUD проявляется с анимацией | |

Кадр зависит только от времени. Поэтому пропуск, повтор и `?t=` работают без отдельного состояния.
Время задаёт музыка: движок мягко следует за позицией в треке, а гул и взрыв запланированы
от того же нуля. Пропуск перематывает трек, поэтому музыка в меню продолжается с той же
точки. Трек зациклен целиком: он заканчивается тишиной и начинается тихим пэдом.

## Как устроена картинка

| Файл | Что делает |
| --- | --- |
| `src/render/fracture.ts` | режет сферу на плиты до старта: трещины идут по настоящим разломам |
| `src/render/shaders/studio.ts` | логотип студии: полоса света, дым, пыль, в том же HDR-проходе |
| `src/render/shaders/planet.ts` | поверхность, облака, города, трещины, остывающая порода |
| `src/render/shaders/volume.ts` | атмосфера, огонь, ядро, кольцо, в отдельном проходе с глубиной |
| `src/render/shaders/post.ts` | bloom, лучи через щели, анаморфная полоса, ACES, грейд, зерно |
| `src/ui/hud.tsx`, `src/ui/hud.css` | меню и порядок его появления |
| `src/audio/sound.ts` | музыка и её часы, гул, взрыв, звуки интерфейса |

## Ассеты

Исходники лежат в `art/source`, все сгенерированы через Codex `image_gen`.
`python3 tools/prepare-assets.py` делает из них `src/assets`: закрывает шов карты,
строит маски океана и городов, переводит логотип в альфу и печёт тайловый 3D-шум.
Логотип студии это `art/source/harwex-b.png`. Варианты `harwex-a` и `harwex-c` не используются.

`tools/shots.mjs` снимает кадры на настоящем GPU, `tools/check.mjs` проверяет
FPS, экран запуска, синхронизацию с музыкой, клавиши, пропуск, повтор и reduced motion.
