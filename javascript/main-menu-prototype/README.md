# Главное меню «Острова»

Кинематографичное главное меню: планета трескается, взрывается, и из пыли выходит
уцелевший остров, над которым появляется HUD. Стек тот же, что в `ostrov-prototype`:
React, rspack, TypeScript, three.js. Звук синтезируется в браузере, аудиофайлов нет.

```bash
npm install
npm run dev        # сервер на свободном порту, адрес будет в консоли
npm run build      # сборка в dist/
npm run typecheck
```

## Управление

| Клавиша | Действие |
| --- | --- |
| любая клавиша, клик | пропустить заставку и открыть звук |
| ↑ ↓, Home, End, мышь | выбор пункта |
| Enter, клик | выбрать пункт (пока заглушка) |
| ← → | сложность |
| R | заставка заново, теперь со звуком |
| M | звук |

Браузер не даёт играть звук до первого действия пользователя, поэтому первый запуск
идёт без звука. `?t=3.4` в адресе останавливает кадр на нужной секунде.

## Раскадровка

Все моменты собраны в `TIMELINE` в `src/core/timeline.ts`:

| Секунды | Что происходит |
| --- | --- |
| 0–1 | чёрный экран проявляется в планету, HUD нет |
| 1–6 | взрыв: трещины, вдох, вспышка на 2.8, огонь, остров из пыли на 4.3 |
| 6+ | HUD проявляется с анимацией |

Кадр зависит только от времени. Поэтому пропуск, повтор и `?t=` работают без отдельного состояния.

## Как устроена картинка

| Файл | Что делает |
| --- | --- |
| `src/render/fracture.ts` | режет сферу на плиты до старта: трещины идут по настоящим разломам |
| `src/render/shaders/planet.ts` | поверхность, облака, города, трещины, остывающая порода |
| `src/render/shaders/volume.ts` | атмосфера, огонь, ядро, кольцо, в отдельном проходе с глубиной |
| `src/render/shaders/post.ts` | bloom, лучи через щели, анаморфная полоса, ACES, грейд, зерно |
| `src/ui/hud.tsx`, `src/ui/hud.css` | меню и порядок его появления |
| `src/audio/sound.ts` | гул, взрыв, хор, звуки интерфейса |

## Ассеты

Исходники лежат в `art/source`, все сгенерированы через Codex `image_gen`.
`python3 tools/prepare-assets.py` делает из них `src/assets`: закрывает шов карты,
строит маски океана и городов, переводит логотип в альфу и печёт тайловый 3D-шум.

`tools/shots.mjs` снимает кадры на настоящем GPU, `tools/check.mjs` проверяет
FPS, клавиши, пропуск, повтор и reduced motion.
