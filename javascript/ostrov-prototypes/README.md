# Прототипы Острова

Хранилище прототипов игры. Каждый прототип лежит в своей папке `prototypes/<id>/`,
собирается отдельно и открывается по своей ссылке. Стек: TypeScript, React, three.js, rspack.

```bash
npm install
npx playwright install chromium   # один раз, для снапшотов и проверок
npm run dev                       # список прототипов и ссылки на каждый будут в консоли
```

| Команда | Что делает |
| --- | --- |
| `npm run dev [-- <id> …]` | все прототипы на одном порту: `/` это список, `/<id>/` это прототип |
| `npm run new -- <id> "<название>" "<описание>"` | новый прототип из шаблона |
| `npm run check [-- <id>]` | изоляция и типы одного прототипа или всех |
| `npm run snapshot -- <id> [view …]` | скриншоты в `.snapshots/<id>/` |
| `npm run with-server -- <id> <команда>` | собрать и поднять прототип, запустить его скрипт, `{url}` это ссылка |
| `npm run build [-- <id> …]` | статическая сборка в `dist/` |

Ошибка или пересборка одного прототипа не ломает и не перезагружает страницу другого:
у каждого свой компилятор и свой канал live reload. Правила изоляции и работа через субагентов
описаны в `CLAUDE.md`.

Список прототипов с описаниями показывает главная страница `npm run dev`.
